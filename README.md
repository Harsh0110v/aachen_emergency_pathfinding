B208 Advanced Algorithms assesment 
 project that uses graph path finding algortighms to find the shortest route from varied locations in freiburg, city in germany. There are two algortihms that are implementd and compared, Dijkstra algorthm and A* . 
 WHAT IT DOES

Aachen is represented as a weighted graph where locations are in form of nodes and roads between them are edges which have distance in km. Five different hospitals are placed as target nodes.for every nodes there are five different starting location,both algortihms find the shortest road network path to the nearest hospital.
How to run
python freiburg_pathfinding.py running this script will automatically run the code and print the result. OUTPUT for every scenario, you will be able to see
Which hospital is nearest
the total distance in km
the exact path taken, node to node
how many nodes have been explored by each of algorithm
running time
memory usage
validation of both algorithm giving the same answer
